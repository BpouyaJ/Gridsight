# Generated analytical results

This directory contains small, reviewable analytical outputs derived from the
verified PostgreSQL reporting layer. Full row-level datasets remain ignored
under `data/processed/`.

`kpi_snapshot.json` is generated by:

```powershell
python -m gridsight.reporting.build_kpis
```

The snapshot is deterministic for unchanged reporting data and query code. It
contains aggregate public-data results, declared units, source attribution,
and query-contract metadata suitable for Git and portfolio review.

The verified Step 5.1 artifact has SHA-256
`fa03ee1af919027634aeb45a524c713274bd9effcac9955052d3be449c8395fc`.

`eda_snapshot.json` and the four files under `reports/figures/` are generated
by:

```powershell
python -m gridsight.reporting.build_eda
```

The EDA builder verifies the KPI dependency and all monthly, local-hour, and
daily grains before publishing descriptive results.

`final_evaluation_snapshot.json` is generated with the ignored row-level test
prediction artifact by:

```powershell

```

already-selected design on train plus validation rows, and publishes the one
final 2025 comparison with both seasonal-naive baselines. The snapshot contains
aggregate overall and horizon metrics; the detailed 8,760-row predictions stay
ignored under `data/processed/`.


manifest before freezing eight Power BI/Excel data products and their checked
sample-extract policies. Step 7.2 updates the same contract after implementing
the two forecast SQL marts; public sample files remain Step 7.3.
