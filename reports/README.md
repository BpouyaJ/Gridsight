# Generated analytical results

This directory contains small, reviewable analytical outputs derived from the
verified PostgreSQL reporting layer. Full row-level datasets remain ignored
under `data/processed/`.

`kpi_snapshot.json` is generated by:

```powershell
python -m gridsight.reporting.build_kpis
```

The snapshot is deterministic for unchanged reporting data and query code. It
contains aggregate public-data results, declared units, source attribution,
and query-contract metadata suitable for Git and portfolio review.

The verified Step 5.1 artifact has SHA-256
`fa03ee1af919027634aeb45a524c713274bd9effcac9955052d3be449c8395fc`.

`eda_snapshot.json` and the four files under `reports/figures/` are generated
by:

```powershell
python -m gridsight.reporting.build_eda
```

The EDA builder verifies the KPI dependency and all monthly, local-hour, and
daily grains before publishing descriptive results.

`forecast_contract.json` is generated by:

```powershell
python -m gridsight.forecasting.build_contract
```

It records the deterministic Step 6.1 schedule, information cutoff,
chronological splits, target, metric definitions, row counts, and ignored
forecast-index hash.

  `6089b1d7c2cd3298cfa3d24526f98cc763b1c95947ce2e9e84ff06dc42bbecc4`.

`baseline_snapshot.json` is generated by:

```powershell
python -m gridsight.forecasting.build_baselines
```

It contains only aggregate Step 6.2 train and validation metrics, their
24-step horizon profiles, the stronger validation baseline, frozen-input
hashes, and an explicit zero-test-row record.

The verified `baseline_snapshot.json` SHA-256 is
`311513a0405761aa6a30db6a956b53c29b3cc38dfd03dc4e74efa62902a4b717`.

`feature_contract.json` is generated with the ignored row-level feature matrix
by:

```powershell
python -m gridsight.forecasting.build_features
```

It records Step 6.3 feature names and families, split counts, redacted-test
rules, frozen-input hashes, and the ignored matrix hash.
