# Generated analytical results

This directory contains small, reviewable analytical outputs derived from the
verified PostgreSQL reporting layer. Full row-level datasets remain ignored
under `data/processed/`.

`kpi_snapshot.json` is generated by:

```powershell
python -m gridsight.reporting.build_kpis
```

The snapshot is deterministic for unchanged reporting data and query code. It
contains aggregate public-data results, declared units, source attribution,
and query-contract metadata suitable for Git and portfolio review.

`fa03ee1af919027634aeb45a524c713274bd9effcac9955052d3be449c8395fc`.
